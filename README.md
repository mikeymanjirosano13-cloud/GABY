# G.A.B.Y.

## 🤖 Sobre

G.A.B.Y. (General Artificial Brain for You) é um projeto de inteligência artificial modular inspirado em assistentes como o J.A.R.V.I.S., desenvolvido em Python.

O objetivo é criar uma IA pessoal capaz de conversar, aprender, automatizar tarefas, integrar-se ao GitHub, utilizar voz, visão computacional, memória de longo prazo e executar plugins.
